## 1. 品牌

| 用途 | 值 |
|---|---|
| 主紫 violet | #5B54E8 |
| 深紫（渐变终点、CTA）| #4D46D2 |
| 浅紫（渐变起点）| #7A72EA |
| 按钮渐变 | 60deg #7A72EA → #4D46D2 |
| 重点字 / 标题强调 | #4F46E5 |
| 小标签 eyebrow | #6366F1 |

| 墨色 | #0F172A / #1E293B |

| 浅底 | #F4F5FB |
| 结尾深色带 | #0E1134 → #1C1A5C → #2A1F78 |

- 卡片：白底、圆角约 20px、带一点紫色光晕阴影。
- 字体：英文 Instrument Sans，中文 Noto Sans SC；**重点字用最粗（900）**。
- Logo：用真文件，不要重画。本 skill 带了 `assets/logo/nexjarvis-brandmark.png`（品牌登场用的就是它，导入后把 asset ID 填进 `v2-05-brand-reveal.jsx` 的 `logoId`）、`nexjarvis-primary-blue.png`、`nexjarvis-primary-white.png`。完整的 logo 包（SUBMARK、LOGOTYPE、.ai、logo 动画 .mov）在原剪辑者的 `~/Desktop/NexJarvis/logo/`。
- 这些值也存在 `assets/mg-kit/nj-kit.jsx` 的 `NJ` 常量里，MG 里一律从那里取。

## 2. 画面、安全框和对齐

- 1080×1920，25fps。
- 用户的 IG Reels 边框（`assets/ig-reels-safe-frame.png`）：字幕和 MG 不能碰绿色边框（上 108、下 320、左 60、右 120 px），也要避开上方两条粉色虚线之间（y 139–149 到 248–258）。可用范围：**x 60–960，y 270–1600**。
- **左右对齐看画面正中 x=540**，不是安全区中线 510。因为右边只到 960，以 540 居中的内容最宽 840px（x 120–960）。（012 时用户要求「检查看看所有 mg 动画是不是都是在画面正中间，左右要 align 好」，当时全部偏左 30px。）
- 实拍画面照常铺满全屏，安全框只管叠在上面的文字和图形。

常用摆位：

| 东西 | 摆位 |
|---|---|
| 顶部 MG（1000×400 画布）| left 90、top 268、900×360（缩成 0.9，画布 x=500 正好落在 540）|
| 顶部 MG（1000×450 画布）| left 90、top 262、900×405 |
| 全屏 MG（产品页面、CTA）| 0,0、1080×1920，`centerX` 属性设 540 |
| Hook 标题卡 | 可以偏右放在主持人手势旁（012：left 384、top 640、582.8×413.6，用户确认保持在右侧）|
| 字幕框 | left 120、top 1290、840×220（以 540 居中）|

- 顶部 MG 可用高度大约 y 270–690，再往下会压到主持人头发；离头发至少留约 40px。
- 1000 宽画布里横排三个图标放在 x 190 / 500 / 810，两个放在 310 / 690，一个放 500。

## 3. 字幕

模板：`assets/mg-kit/caption-nj.jsx`（Remotion），挂在字幕轨上，属性 `shadowOpacity: 0.6`。

| 项目 | 规格 | 由来 |
|---|---|---|
| 底 | 没有底卡 | 014 用户否决了白卡深字的第一版 |
| 普通字 | 白色 #FFFFFF，中文 Noto Sans SC 800，英文 Instrument Sans 700，66px | 「字体颜色换成白色」 |
| 阴影 | 0 3px 8px，黑色 60% | 先是 40%，后来「所有白色字的阴影再重一点，放60%」 |
| 重点字 | #4F46E5、900、放大 1.1 倍，放在白色小底块上（圆角 0.3em），底块阴影单独 40%；相邻重点字共用一块 | 「重点字加底色」，颜色不变 |
| 未念到的字 | 82% 不透明，念到时变 100% | 白字在亮背景上要够清楚 |
| 行数和字数 | 每张一行，**5–8 个字**（英文一个词算一个字）| 014 提出，2026-11-23 确认为系列规则 |

- 超过 8 字就 `split_card` 拆成两张；拆开会切断词、或和下一句合并会超过 8 字的短句，可以少于 5 字，不要硬拆（014 用户选了自然断句）。
- **每一张都手动选重点字**，不要用自动的（自动会挑到「我去」这种字）。选这句最关键的名词、动词或数字；连接词、口头禅不选（「那说一下」不做重点）；重点要整词（「上上上次」四个字一起，不能漏第一个「上」）。
- 用词以脚本为准，修正识别错误：品牌名写 NexJarvis；口误尾巴删掉（「你就回不去了要」→「你就回不去了」）；马来西亚口语照说的写（「Gaodim！」）。
- 字幕挡到画面里的重点（例如手机上的 logo）时，先给用户选项，不要自己去移整段画面（014 试过放大上移 10%，用户要求回到原样）。

## 4. MG 的类型和排版

**先判断这一段是哪一类，再选排版**，不要整集用同一种（012 时用户说「不要全部都换」）。

| 内容类型 | 排版 | 例子 |
|---|---|---|
| 并列的几个重点 | 一排圆形渐变图标，下面各一个小标签，可带数字角标；浮在主持人头顶 | Supplier / Customer / Subscribe（`v2-03-inbox.jsx`），每天 30 分钟 + MISS（`v2-04`），对的时候 / 提醒我 / 不怕忘记（`v2-07`）|
| 有规律的步骤 | 全屏的产品页面 MG（例如邮件客户端），用虚拟镜头跟着步骤或鼠标移动、推近；**放在人物后面**，人物抠像盖在上面；上方一排步骤标签逐个打勾 | AI 写 Draft → 对应 Email → 点 Send（`v3-08-email-page.jsx`）|
| 一个过程 | 小流程动画；用户画了草图就照草图 | 乱信堆 → 中间 NJ bot 吸进去 → 分进三个篮子（`v3-06-sort-baskets.jsx`）|
| 产品功能本身 | 一张会「动起来」的功能卡，要演出 NexJarvis 做了什么 | 会议记录卡片逐项点亮 + 「一字不漏」功能横幅（`014-05`）；翻回上次 / 上上次 / 上上上次会议，盖「未解决」章（`014-06`）|
| 品牌登场 | 一句引导语 + 带真 logo 的品牌胶囊 + 几颗星芒 | 「可是今天我有」+ NexJarvis（`v2-05`）|
| 一个按钮就搞定 | 按钮被点 → 完成状态 + 计时 | 一键搞定（`014-07`），Send → Gaodim! + 只用 1 分钟（`v2-09`）|
| Hook | 小标题卡：一行先出、第二行在关键句砸下来，加一个小 chip | 「Email 小助理 / 回不去了！」+「1 分钟搞定」（`01-hook-title.jsx`）|

共同规则：
- **图案优先，文字只做短标签**（「左边进、右边出」用一个头加两只耳朵表示；「不要只有文字而已」）。
- **要把意思讲对**。MG 里的分类要和产品逻辑一致（「一字不漏」是 NexJarvis 的能力，不是会议记录里的一项）。用户嫌不够生动时，想一个能「演出」那个能力的画面，而不是加更多字。
- **跟着字出现**：每个元素对准那个词在口播里出现的帧（从 transcript 的词时间取），整个 MG 在那句话开头前约 2 帧进场。
- 每个 MG 是一整段连续的 clip，MG 之间不重叠。
- 没有真实内容的地方用占位横条，不要编假内容；非编不可的（示例邮件、补充语）做成 MG 属性，并在交片时告诉用户。
- 所有 MG 都用 `nj-kit.jsx` 的组件和颜色：`IconItem`、`IconBubble`、`LabelPill`、`Badge`、`Card`、`Eyebrow`、各种 Icon（Mail、Send、Pencil、Trash、Eye、Bell、Clock、Calendar、Stopwatch、Warning、Star、Flag、Mic、Chat、Shield、Mute、Spark、Cursor、User、Doc、Package、Check、Arrow、Close）、`Face`、`Ear`、`NjBot`。

## 5. 动效

- **不要回弹。** 进场和退场都是 0.3 秒左右的三次方缓出（`Easing.out(Easing.cubic)`），不要 overshoot、退场前不要先放大、不要用放大缩小来强调。（012 时用户先要求「多加一些弹跳」，看过后改口「bounce 太多了，先不要用 bounce 好了」，以后者为准；要加回来先问。）
- 小幅的持续动作可以留：图标轻轻上下漂（±5px）、铃铛摇、「miss」时抖一下、打字。
- 时间线上的关键帧（画面缩放、位置）也全部用 `ease-out-cubic`。

## 6. NJ bot

- 默认：口播提到「小助理」或「AI」时，表示它的图标直接换成 NJ bot（`v2-02-assistant.jsx` 和 `v3-06-sort-baskets.jsx` 都有 `botImage` 属性，填 bot 图的 asset ID 就会用 bot，留空就是原来的图标）。
- 要有一点表情：介绍时开心眼，问句时睁大眼歪头，工作时专注眼，分东西时转头看篮子，完成时开心。
- **不要做满场走位的 bot 表演**，除非用户要。012 做过整条 bot 跟着主持人互动的版本（专案里的「含 NJ bot 版」时间线），用户最后决定不用。
- 图：`assets/nj-bot-cutout.png`（1024×1024 透明底，主体在 x 310–709、y 338–772）。用整张真图，`NjBot` 只在面罩上重画眼睛，不要用代码重画整个 bot。眼睛表情：normal、wide、focused、sleepy、happy、worried、determined、dizzy、star。

## 7. 画面缩放

- **开头镜头**：一条连续片段，关键帧从 100% 推到 120%，不要硬切。
- **口播段底图**略放大来收紧构图（014 105%，012 112%），以主持人头顶为锚点放大，这样头不会往上顶到 MG，也不会露黑边。
- **跟着字推近**：重点词推近 6–12%，用 4–5 帧推进，说完用 6–8 帧拉回。用户喜欢多一点 zoom in / zoom out。
- **递进的词等距递增**：点头、点头、点头 → 106 / 112 / 118%；上次、上上次、上上上次 → 最后一级 135%，前两级等距。
- **同一条素材的跳剪**：后一段的第一帧和前一段的最后一帧位置、大小一样，然后慢慢漂到它自己的缩放（用户选了「慢慢漂」，不要先停住再快速移动）。不同机位之间不用对齐。
- 所有关键帧 `ease-out-cubic`。

## 8. 声音

| 项目 | 设定 |
|---|---|
| 降噪 | 背景噪音大时，对口播 clip 做 AI 人声隔离（012 做了）|
| 每段口播 | normalize-loudness −16 LUFS；clip 边缘淡入淡出 2 帧 |
| 总线 | Limiter：inputGainDb 13，releaseMs 80 |
| 口播 clip gain | 调到人声约 −11.9 dBFS RMS（014 原声很小用了 +8 dB；012 隔离后用了 −1.5 dB）|
| 整体 | 约 −9.5 LUFS，峰值约 −1 dBFS |

- 这个电平比 IG 的 −14 LUFS 标准响很多，是用户自己要的（014「人声再放大 20%」，听过提醒后没有改回）。新一集照这个对齐；差很多时告诉用户。
- 我听不到声音，只能量电平。人声隔离有没有怪声、音效音色合不合适，都要请用户听。

## 10. BGM

- 默认 `assets/music/cc0_bgm-b_the-lucky-ticket.mp3`（Antenalosmusic，CC0，约 100 BPM，38.4 秒，friendly / light / optimistic）。
- −36 dB，淡入 20 帧，淡出 12 帧；从第一个口播镜头开始到片尾。开头如果是小剧场 hook（014），那段不放音乐，保留冷场和环境声。
- 备选同在 `assets/music/`：Rabbit Bop（马林巴，更俏皮）、Arcade Aroma（复古放克，很满，垫口播可能抢戏）。
- Openverse 用 `category=music` 加 CC0 搜不到东西，要去掉 category、用 `length=short,medium` 过滤。

## 11. 结尾

- 口播说「关注我们 / 关注 NexJarvis」时，上方出现「关注 NexJarvis」按钮（光标点一下，+ 变 ✓）和「明天 一分钟 解决什么？」chip（`10-cta.jsx`）。
- 主持人走出画面后，按钮组滑到画面正中放大，停到最后一帧，不淡出。
- 素材结束后在 V1 放 `11-end-bg.jsx`（品牌深色渐变 + 紫色光晕），约 1.6 秒（40 帧）。不要黑底（014「结尾背景换上适合的颜色」）。
